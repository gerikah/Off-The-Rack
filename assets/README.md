# Source assets

- `jackets/` contains original product photography.
- `logo/` contains original brand artwork.
- `background.png` is the original storefront background.
- `email/` contains the Emailify/MJML welcome-email design export.

Run `npm run assets` to generate the optimized image derivatives under `public/images/`. Run `npm run assets:social` to regenerate sharing artwork and app icons. Keep these originals so generated assets can be rebuilt.
